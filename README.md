# 헤스랩 v6.3 검토 시안

헤스랩 브랜드 정보와 페이지별 제목·설명, 센터 공간 사진을 사용한 공유 미리보기를 정리한 검토용 사이트입니다.

이전 v6 검토 사이트와 별도입니다. 검토 화면은 검색 중복을 피하기 위해 noindex로 설정했습니다.
close 파일은 표시용 인코딩이며 소스의 암호화나 완전한 비공개를 의미하지 않습니다.
검색 운영용 원본은 별도의 정적 HTML 패키지로 관리합니다.
폰트 라이선스는 OFL.txt, 서브셋 수정 고지는 FONT_NOTICE.txt를 확인하세요.

# 헤스랩 v6.6.01 검토 시안

기존 v6.3 검토 링크에 최신 v6.6.01을 반영한 공개 검토 화면입니다.
메인 설명 아래 프로그램·날짜·예약을 배치하고, GNB 아래에서 비주얼이 시작하도록 수정했습니다.
온·보·회·활·련·청 프로그램과 메인 회복이야기, 센터소개, 산모교실, 아카데미를 제공합니다.

검토 화면은 noindex입니다. close는 JavaScript로 화면을 복원하는 인코딩이며 소스의 암호화나 완전 비공개 기능이 아닙니다.
실제 예약은 네이버에서 프로그램·날짜와 예약 가능 여부를 확인하고 확정합니다.
폰트 고지는 OFL.txt 및 FONT_NOTICE.txt에 포함합니다.
